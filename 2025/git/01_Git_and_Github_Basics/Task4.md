# ✅ Task 4: Explore Your Commit History

## 🔍 View the Git Log

To inspect your commit history, follow the steps below:

---

### 📂 Step 1: Navigate to Your Repository Folder

```bash
cd 90DaysOfDevOps/2025/git/01_Git_and_Github_Basics
```

---

### 📝 Step 2: View Commit History Using Git Log

```bash
git log
```

You will see output similar to this:

```
commit 19ca909f8e71fe8396f0f682ddefd05057c9c498
Author: Ansh8700 <ansh.devops.er@gmail.com>
Date:   Thu Jul 10 13:12:14 2025 +0530

    ✨ Added info.txt with personal intro

commit 72a5e85d7f4d8fc6c9a9f8c9673f21341c3acbaa
Author: Ansh8700 <ansh.devops.er@gmail.com>
Date:   Mon Jul 14 18:05:11 2025 +0530

    📁 Initialized Git repository and created week-4-challenge directory
```

---

### 🧠 What to Take Note Of:

For each commit, record the following:

* ✅ **Commit Hash**: The unique ID (e.g., `9fceb02b...`)
* ✅ **Commit Message**: What change was made (e.g., "Added info.txt")
* ✅ **Author Name and Email**
* ✅ **Timestamp**
