# 📝 Task 2: Initialize a Local Repository and Create a File

### 📁 1. Set Up Your Challenge Directory

Inside the cloned repository, create a new folder for this challenge:

```bash
mkdir week-4-challenge
cd week-4-challenge
```

### 🔧 2. Initialize a Git Repository

Initialize a new Git repository inside this directory:

```bash
git init
```

> ✅ This will create a `.git` folder, marking it as a Git-managed project.

### 📄 3. Create a File

Now, create a file named `info.txt` and add some content (e.g., your name and a short intro):

```bash
echo "Hi, I'm Ansh Gupta – a DevOps engineer exploring Git fundamentals!" > info.txt
```

> You can also edit the file manually using a text editor like `nano`, `vim`, or VS Code.

### ✅ 4. Stage and Commit Your File

Stage the new file using `git add`, then commit it with a meaningful message:

```bash
git add info.txt
git commit -m "Initial commit: Add info.txt with introductory content"
```
