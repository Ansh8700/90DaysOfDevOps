# ✅ Task 1: Fork and Clone the Repository

## 🔁 Fork the Repository

1. Visit the original GitHub repository:
   👉 [https://github.com/TrainWithShubham/90DaysOfDevOps](https://github.com/TrainWithShubham/90DaysOfDevOps)

2. Click the **Fork** button (top-right corner) to create a copy under your own GitHub account.

---

## 💻 Clone Your Fork Locally

1. Copy the HTTPS URL of your forked repository.
   Example:

   ```
   https://github.com/<your-username>/90DaysOfDevOps.git
   ```

2. Open your terminal and run the following commands:

```bash
# Clone your fork
git clone https://github.com/LondheShubham153/90DaysOfDevOps.git

# Change directory to the Day 1 Git & GitHub Basics folder
cd 90DaysOfDevOps/2025/git/01_Git_and_Github_Basics
```

> ✅ Replace `<your-username>` with your actual GitHub username.
